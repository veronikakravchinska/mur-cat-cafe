# Котокафе «Мур»

Сервіс для котокафе «Мур»: облік котів-резидентів, бронювання столиків і правила спілкування з котами.
Гості заздалегідь бронюють столик, бачать, які коти сьогодні «на зміні», і погоджуються з правилами поводження з тваринами.
Персонал веде картки котів: здоров'я, характер, режим відпочинку.

## Ключові функції
- **Каталог котів-резидентів** — картки з фото, характером, станом здоров'я і статусом «відпочиває / готовий до спілкування»
- **Бронювання столиків** — вибір дати, часу і кількості гостей з обмеженням місткості залу
- **Правила спілкування з котами** — гість підтверджує ознайомлення з правилами перед візитом
- **Розклад відпочинку котів** — кіт автоматично стає недоступним після ліміту часу спілкування
- **Ролі доступу** — гість, адміністратор залу, ветеринар

## Стек технологій
- Python 3.12, FastAPI
- PostgreSQL
- pytest
- GitHub Actions (CI/CD)

Git Flow: `main` — релізи, `develop` — інтеграція (гілка за замовчуванням),
`feature/<№ issue>-<опис>` від `develop`, `release/x.y.z`, `hotfix/<опис>` від `main`.
Коміти — у форматі Conventional Commits з областю `cats`, підписані GPG-ключем.
