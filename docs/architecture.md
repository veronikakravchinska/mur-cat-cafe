# Архітектура котокафе «Мур»

- **Веб-інтерфейс** — каталог котів, бронювання столиків, правила спілкування
- **API** — бізнес-логіка, перевірка прав доступу
- **Автентифікація** — вхід користувачів і ролі: гість, адміністратор залу, ветеринар
- **База даних** — коти, гості, столики, бронювання
- **Сервіс розкладу** — облік часу спілкування і відпочинку котів
